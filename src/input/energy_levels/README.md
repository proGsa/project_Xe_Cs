Здесь находятся приложенные пользователем исходные NIST CSV:
`xe_1.csv` ... `xe_5.csv`, `cs_1.csv` ... `cs_5.csv`.
Суффикс 1 соответствует нейтралу, 2 — заряду +1 и так далее.
При max_charge=1 используются только файлы с суффиксами 1 и 2.
Минимальные поля — энергия уровня и J или статистический вес g.
Образцы поддерживаемых заголовков приведены в основном README.
