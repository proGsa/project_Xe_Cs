# Данные для ксеноновой плазмы при Te = Th

Подготовлено 26 ноября 2026 года. Здесь `gamma_Te_Th = Te/Th = 1`.
Основной случай нашего проекта: **чистый Xe, p = 100 000 Па, T = 3000…30 000 К,
электроны, нейтральные атомы и ионы с зарядами +1…+4**.

Пакет содержит исходные атомные данные, столкновительные интегралы, параметры
моделей и опубликованные расчётные значения свойств для сравнения. Полный
решатель транспортных коэффициентов на Python в этот пакет не входит.

некулоновских интегралов в статье. Для первого сравнения используйте
**`reference/xe_lte_100000Pa_traditional.csv`**. Ветви не означают «идеальная» и
«неидеальная» плазма: обе содержат результаты модели статьи с её поправками.

## Диапазоны и единицы

Опубликованные таблицы свойств: **300…30 000 К, шаг 100 К**, давления
**1, 2, 5, 10, 20, 50, 100 бар**. В нормализованных файлах давление всегда в Па.
Всего 14 таблиц по 298 строк: 4172 состояния с учётом двух ветвей переноса.

Каждый некулоновский файл содержит 16 порядков интегралов:
`(1,1)…(1,7)`, `(2,2)…(2,6)`, `(3,3)…(3,5)`, `(4,4)`.
У e–Xe 33 температурных узла, у Xe–Xe и Xe–Xe+ — 298. Общий диапазон
300…30 000 К. Температурная сетка e–Xe неравномерная.

**Столбцы интегралов содержат πΩ^(l,s), единица м².** В оригинале это Å²:
умножено на 10⁻²⁰, множитель π сохранён. Это не частота столкновений в с⁻¹
и не сечение как функция энергии. При подключении формул Чепмена—Энскога
необходимо согласовать их определение Ω с этим определением.

У кулоновских таблиц аргумент — безразмерная температура T*, а не T в К.
Диапазон **0.1…10 000**. Физические интегралы зависят также от зарядов и
дебаевской длины, поэтому единого файла Ω(T) для всех кулоновских пар нет.

## Три ограничения, которые нельзя пропустить

1. **Давление в исходных именах файлов.** Авторы написали `1 atm`, `2 atm` и
   т. д., но лицензия приложения и основной текст статьи указывают бары.
   Проверка `n_total kB T` при 300 К даёт 100 000 Па на единицу подписи,
   а не 101 325 Па. В пакете принята шкала в барах, исходные файлы сохранены
   без изменений. Численные проверки: `reference/pressure_interpretation.json`.
2. **Несколько разных «гамм».** Наше отношение температур — `gamma_Te_Th`.
   Исходный столбец γ в термодинамической таблице — **Cp/Cv**; здесь он
   назван `adiabatic_index_cp_cv`. Производные диагностические параметры
   `Gamma_e_DH_derived` и `Gamma_e_WS_derived` описывают разные определения
   кулоновского взаимодействия. Они не заменяют Γ из семинарской модели.
3. **Нет готовых парных таблиц для Xe–Xe2+, Xe–Xe3+, Xe–Xe4+.** Среди проверенных
   данных приложения они отсутствуют. Для этих трёх пар записана возможная
   поляризационная модель `V = −C4/r⁴` и вычислены C4. Это параметризованный
   кандидат, который требует выбора модели рассеяния, короткодействующей части
   и учёта переноса заряда. Он не выдан за опубликованные интегралы.

Следовательно, **таблицы всех интересующих нас свойств для сравнения уже есть**.
Для собственного независимого расчёта σ основные столкновительные входы
собраны; для полного многокомпонентного расчёта η и λ ещё нужно закрыть
указанные три пары и реализовать согласованную транспортную схему.
Эти ограничения не мешают начать с нейтрального и слабо ионизованного Xe.

## Совместимость с нашим расчётом концентраций

Атомные CSV взяты из ранее приложенного пользователем проекта, а не загружены
заново из NIST. Дата экспорта и версия ASD неизвестны. Исходные файлы находятся
в `raw/nist`, отчёт обработки — в `atomic/import_report.json`.

В нормализованном наборе принято 342, 161, 157, 94 и 53 уровня для зарядов
0…4. Использованы связанные уровни ниже исходного порога; строки пределов
и уровни выше порога исключены. Сведения о причинах исключения, оценочных
значениях и исходных обозначениях сохранены в отчёте. Спектральное обозначение
**Xe I — нейтрал, Xe II — +1, Xe V — +4**.

В статье плотностное снижение порога влияет также на отсечение уровней в
статистической сумме; в нашей прежней семинарской реализации использовался
фиксированный набор уровней и другая неидеальная поправка. Поэтому даже при
Te = Th расхождение с таблицей статьи само по себе не доказывает ошибку программы.
При сравнении нужно согласовать уравнение состояния, поправки и набор уровней.

## Быстрый запуск

Распаковать архив, перейти в каталог `xe_lte_data`:

```bash
uv run --no-project python example.py
uv run --no-project python validate_data.py
```

Для этих двух команд достаточно стандартной библиотеки Python; можно заменить
`uv run --no-project python` на `python`.

```python
from xe_data import XeData

data = XeData()
reference = data.reference(10000, pressure_Pa=100000, branch="traditional")
sigma = reference["sigma_S_m"]
eta = reference["eta_Pa_s"]
lambda_total = reference["lambda_total_W_m_K"]

# Входной интеграл, а не готовая электропроводность:
pi_omega_e_Xe = data.collision_integral(10000, "Xe0_e", l=1, s=1)
```

Чтение эталонов использует линейную интерполяцию по T; столкновительных
интегралов — линейную по логарифмам аргумента и значения. На узлах возвращаются
исходные значения. Экстраполяция и интерполяция по давлению запрещены.
Интерполированные эталоны не обеспечивают точного выполнения всех балансов;
для проверки уравнений лучше использовать узлы таблицы.

`ideal_thermodynamics(T, concentrations)` отдельно вычисляет идеальные u, e, h,
ρ и p из переданного состава. Это наша формула с фиксированным набором уровней,
а не интерполяция статьи; теплоёмкости и транспорт она не рассчитывает.

## Что ещё находится в архиве

- `FORMULAS.md` — определения величин, формулы и порядок подключения данных.
- `COLUMN_GUIDE.csv` — точное назначение и единицы каждого столбца эталонов.
- `sources.json` — происхождение, версии, ссылки, контрольные суммы.
- `validation.json` — диапазоны, численные особенности исходных файлов и
  проверка применимости кулоновских таблиц при 1 бар и 3000…30 000 К.
- `validation_run.json` — результат выполненных проверок пакета.
- `manifest_sha256.json` — контроль целостности всех поставляемых файлов.
- `upstream/PPFM-0.2.0-zenodo.zip` — опубликованный исходный код методов.
  Это справочный исходник, а не готовая конфигурация для Xe. Версия выпущена
  раньше статьи; точное совпадение с её расчётной версией не установлено.

В исходных таблицах встречаются численные нижние границы малых ионных
концентраций, например ровно 1 м⁻³, и отрицательные значения внутреннего
вклада λ. Не все они малы: минимум −0.214214 Вт/(м·К). При **20 бар и 8300 К**
полная сумма λ отрицательна в обеих ветвях: −0.04632877 (`traditional`) и
−0.04479170 (`phenomenological`) Вт/(м·К). Эти две строки нельзя считать
физически достоверными эталонами. Исходные значения сохранены; модуль чтения
блокирует их и использующие их интервалы интерполяции. Для явного просмотра
исходной строки можно передать `allow_flagged=True`. При 1 бар все суммы λ
положительны, но это не равнозначно экспериментальной валидации.
Поле `heat_exchange_source_value` сохранено с исходной подписью `HeatExchange[J]`;
его физическая нормировка здесь не установлена, в рекомендуемые расчёты оно
не включено.
