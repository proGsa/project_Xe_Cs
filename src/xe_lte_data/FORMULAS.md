# Определения и использование данных

Здесь рассматривается Te = Th = T, чистый Xe с зарядами 0…4 и электронами.
Все n — объёмные концентрации, м⁻³. Энергии в формулах — в джоулях.
Нейтральное основное состояние и свободный электрон приняты за нули энергии
образования; возбуждение каждого иона отсчитывается от его собственного
основного состояния. Обозначения энергии: u — Дж/м³, e — Дж/кг, h — Дж/кг.

## Атомные данные и состав

Для заряда z уровни E_zj и веса g_zj берутся из `atomic/energy_levels.csv`:

\[
Q_z(T)=\sum_j g_{zj}\exp[-E_{zj}/(k_B T)],\qquad
\overline E_z=\frac{\sum_j g_{zj}E_{zj}\exp[-E_{zj}/(k_B T)]}{Q_z}.
\]

В NIST энергии возбуждения неотрицательны, поэтому знак в экспоненте
отрицательный. Электронный спиновый множитель 2 входит в уравнение Саха
отдельно, его не следует повторно добавлять в Q_z.

\[
\frac{n_e n_{z+1}}{n_z}
=2\left(\frac{2\pi m_e k_B T}{h_P^2}\right)^{3/2}
\frac{Q_{z+1}}{Q_z}\exp[-I_z/(k_B T)],\quad z=0,1,2,3.
\]

Здесь h_P — постоянная Планка. I_z — энергия перехода z→z+1; она отличается
от накопленной энергии образования \(\chi_z=\sum_{q=0}^{z-1}I_q\).
Пятый порог I_4 нужен для отсечения уровней Xe4+, хотя Xe5+ в составе нет.

Для идеальной плазмы уравнения замыкаются так:

\[
n_e=\sum_{z=1}^4 z n_z,\qquad
p=k_B T\left(n_e+\sum_{z=0}^4n_z\right).
\]

## Идеальная термодинамика из нашего состава

\[
\rho=m_e n_e+\sum_{z=0}^4m_z n_z,\qquad
u_{\rm ideal}=\frac32 k_B T\left(n_e+\sum_{z=0}^4 n_z\right)
 +\sum_{z=0}^4 n_z(\chi_z+\overline E_z).
\]

\[
e=u/\rho,\qquad h=(u+p)/\rho,\qquad
C_p=\left(\frac{\partial h}{\partial T}\right)_p.
\]

Массы m_z ≈ m_Xe − z m_e; поправка массы на энергию ионизации/c² здесь
пренебрежимо мала и не включена. При изменении T равновесные n_z меняются:
для Cp требуется повторно решать задачу состава при том же давлении.
Производная при фиксированных n_z даёт другую теплоёмкость.

В эталонных таблицах e вычислена из опубликованных h и ρ по тождеству
\(e=h-p/\rho\), а не по указанной идеальной сумме. Для полной неидеальной
термодинамики нужны согласованные поправки к свободной энергии и её
производным; нельзя добавлять произвольную поправку к энергии после расчёта.

## Экранирование и кулоновские интегралы

При одной температуре выбрано экранирование всеми заряженными частицами:

\[
\lambda_D=\sqrt{\frac{\epsilon_0 k_BT}
{e_c^2(n_e+\sum_{z=1}^4z^2n_z)}}.
\]

e_c — модуль заряда электрона. Для пары ненулевых зарядовых чисел Z_i,Z_j:

\[
T^*_{ij}=\frac{4\pi\epsilon_0 k_BT\lambda_D}{|Z_i Z_j|e_c^2},\qquad
\pi\Omega_{ij}^{(l,s)}
=\frac{\pi\lambda_D^2}{(T^*_{ij})^2}F_{ij}^{(l,s)}(T^*_{ij}).
\]

F берётся из `coulomb_reduced.csv`: притяжение при Z_i Z_j < 0,
отталкивание при Z_i Z_j > 0. Полученный интеграл имеет единицу м².
Таблица ограничена 0.1 ≤ T* ≤ 10 000. Проверка на опубликованном составе
при 1 бар и 3000…30 000 К показала попадание всех 15 кулоновских пар в
этот диапазон. Это не гарантия для произвольных давлений и составов.

Для диагностических столбцов отдельно определены:

\[
\Gamma_{e,DH}=\frac{e_c^2}{4\pi\epsilon_0\lambda_D k_BT},\qquad
\Gamma_{e,WS}=\frac{e_c^2}{4\pi\epsilon_0 a_e k_BT},\quad
a_e=\left(\frac3{4\pi n_e}\right)^{1/3}.
\]

Это разные параметры. Отношение температур Te/Th везде равно 1.
Семинарский самосогласованный Γ с регуляризованным знаменателем — третье
определение; заменить его одним из этих столбцов без изменения модели нельзя.

Источник использует дебаевские поправки. Их принятые определения записаны в
`models.json`; для химического потенциала частицы z и снижения порога:

\[
\delta\mu_z=-\frac{z^2e_c^2}{8\pi\epsilon_0\lambda_D},\qquad
\Delta I_z=\frac{(z+1)e_c^2}{4\pi\epsilon_0\lambda_D}.
\]

Соответствующая поправка давления в дебаевском приближении:
\(\delta p=-k_BT/(24\pi\lambda_D^3)\). В диагностическом столбце пакета
сохранён её **положительный модуль**, вычисленный из опубликованного состава.
Это не семинарская безразмерная α. Поправки к химическим потенциалам и
отсечение уровней Q_z должны вводиться согласованно; одинаковое снижение
в экспоненте Саха нельзя учитывать дважды.

## Транспорт: что является данными, а что ещё нужно реализовать

σ и η в эталонах даны напрямую; обозначение μ у авторов соответствует нашей η.
Теплопроводность состоит из четырёх вкладов:

\[
\lambda=\lambda_e+\lambda_h+\lambda_r+\lambda_{int}.
\]

Индексы обозначают электронный, поступательный тяжёлых частиц, реакционный
и внутренний вклады. Излучение в эту сумму не включено.
В приложении есть две строки с отрицательной суммарной λ при 20 бар и
8300 К; они помечены как непригодные физические эталоны. Исходные числа
не исправлялись, подробности приведены в README и `validation.json`.

Для собственного расчёта на каждой температуре порядок такой:

1. Вычислить Q_z и решить состав при заданных T и p.
2. Из состава получить ρ, средние энергии, дебаевскую длину и нужные
   термодинамические производные.
3. Для каждой пары частиц собрать требуемые Ω^(l,s) с одинаковой нормировкой:
   три некулоновские пары из таблиц, 15 кулоновских пар из приведённой
   функции F(T*), ещё три пары — из выбранной дополнительной модели.
4. Собрать и решить транспортные линейные системы выбранного приближения
   Чепмена—Энскога. Для плазмы нужны отдельный учёт электронов и тяжёлых
   частиц и согласованный порядок приближения, например схема Devoto или
   Zhang—Murphy из исходников PPFM.
5. Вычислить σ, η, четыре вклада λ и сравнить с эталонами при одинаковых
   физических предположениях. Одно значение Ω^(1,1) не определяет все эти
   коэффициенты.

Для Xe–Xe2+,3+,4+ в пакете есть только кандидат для дальнодействующего
потенциала:

\[
V(r)=-\frac{C_4}{r^4},\qquad
C_4=\frac{(z e_c)^2\alpha_{vol}}{8\pi\epsilon_0},\quad
\alpha_{vol}(Xe)=4.0484\cdot10^{-30}\ \mathrm{m^3}.
\]

Использована объёмная поляризуемость, связанная с поляризуемостью в СИ
через \(\alpha_{SI}=4\pi\epsilon_0\alpha_{vol}\). Смешивать эти определения
нельзя. C4 имеет единицу Дж·м⁴. Из одного дальнего хвоста потенциала нельзя
без дополнительных предположений получить достоверное полное сечение,
учесть перенос заряда и гарантировать совпадение с данными авторов.

Опубликованный архив исходников даёт формулы транспортных матриц и
численные методы. Полная корректность его переноса в Python в рамках
сбора данных не проверялась; готовый пакет не объявляет его точной
реализацией расчётов статьи.
